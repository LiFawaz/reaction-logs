# Reaction Logs

A Valenced-only plugin for Discord Android.

When a reaction is removed, its reaction pill turns red and stays visible locally. Open that reaction's user list to see the account that removed it highlighted in red, including a red outline around their avatar. The red marker is saved on this device and clears when the same emoji is added again or Discord removes that message/reaction set.

The plugin does not add a Configure page or maintain a separate removal-history screen. It only handles the local reaction-pill highlight.

## Install

Add this repository in Valenced:

https://raw.githubusercontent.com/LiFawaz/reaction-logs/gh-pages/index.json

## Important

All reaction markers are stored on this device. The plugin does not change Discord's server-side reaction state.
